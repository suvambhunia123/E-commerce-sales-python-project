📊 E-Commerce Data Analytics Project with Python & Plotly
Welcome to my hands-on data analytics project, where I explore what really drives profit in the e-commerce industry using Python and interactive visualizations with Plotly.

🚀 Project Overview
This project focuses on analyzing historical e-commerce sales data to uncover business insights that can drive profitability and strategic decisions. Using Python and powerful libraries like Pandas and Plotly, I visualized trends and patterns across sales, profit, categories, customer segments, and more.

📌 Key Business Insights
🔍 The analysis surfaced several key takeaways:

📅 Monthly Sales Trends

Peak Month: November

Slowest Month: January

📦 Category Performance

Top Category: Technology

Lowest Performing: Office Supplies

📱 Best Sub-Category

Phones lead in sales among all sub-categories.

💹 Monthly Profit Analysis

Most Profitable Month: December

Least Profitable: January

💡 Profit Drivers

Top Category (Profit): Technology

Top Sub-Category (Profit): Couriers

👥 Best Customer Segments

Sales & Profit: Consumer and Corporate segments perform best.

📈 Sales-to-Profit Efficiency

Highest Ratio: Consumer segment
